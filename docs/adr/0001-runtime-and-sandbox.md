# ADR-0001: Цикл агента и граница исполнения

- Статус: принято.
- Дата: 2026-11-06.

## Контекст

Первый чекпоинт требует объяснимого цикла, двух протоколов, Linux-сборки и реальных Б1–Б5. На Mac 24 ГиБ памяти; модель можно вызывать удалённо. Сравнение кода и документации трёх открытых систем: [исследование](../reference/systems.md).

## Решение

Собственный последовательный Python-цикл, инструменты ReadFile/WriteFile/RunCommand, четыре службы FastAPI. Модель возвращает вызовы, результаты входят в следующий контекст. Завершённый ответ с `finish_reason=stop` без инструментов завершает задачу; независимая проверка файлов определяет успешность БАФ. Лимиты: 30 шагов по умолчанию, максимум 60; запуск 240 с по умолчанию, максимум 600; команда 20 с, максимум 60.

Менеджер создаёт отдельный Docker-контейнер на сессию в выделенной Linux-ВМ. Пользователь 1000, cap-drop ALL, read-only root, no-new-privileges, сеть none, 0.5CPU, 256 МиБ RAM без дополнительного swap, 64PID, /work64 МиБ tmpfs и /tmp16 МиБ. Команды могут читать системные файлы своего образа, но не файлы хоста. Docker socket и ключи доступны только доверенным службам. Рабочие файлы первой демонстрации передаются снимком; это временный режим первого чекпоинта, не выполненное требование монтирования продукта.

## Альтернативы

| Вариант | Польза | Цена и причина выбора другого |
| --- | --- | --- |
| mini-swe-agent2.4.6 | Малый и проверяемый цикл | Всё равно нужны свои протоколы, сессии и ограничения Docker; следующий кандидат для сравнения |
| smolagents1.27.0.dev0 | Типизированные инструменты, исполнение Python | Jupyter-транспорт и состояние не нужны первому пути; сеть none несовместима со стандартным DockerExecutor |
| OpenHands SDK1.60.1 | Готовый сервер и события | Большой объём, amd64/latest defaults требуют переработки |
| Rootless Docker | Меньшие полномочия менеджера | Нужна отдельная проверка делегирования cgroups; не выбран без доказательств лимитов |
| gVisor | Более сильная изоляция ядра | Дополнительный runtime и совместимость ARM; последующее усиление |

## Последствия

Docker socket фактически даёт менеджеру административный контроль выделенной ВМ. Контейнер не является защитой от уязвимости ядра. Colima по умолчанию делится домашним каталогом с VM; песочнице он не подключается, но скомпрометированный менеджер опасен для Mac. Использовать только локальную учебную среду с доверенным клиентом; публичное развёртывание этим решением не покрыто.

Отмена и таймаут уничтожают целый контейнер, включая процессы с новым сеансом (setsid). Они также уничтожают временные файлы: первая версия не обещает восстановление после отмены. Идентификатор освобождённой сессии не переиспользуется. Точное выполнение неизвестной операции после сбоя не повторяется.
